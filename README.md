# AiroRPG

Ein deutschsprachiger, textbasierter Mehrspieler-Rollenspielbot für ein bestehendes IRC-Netzwerk.

## Projektziel

AiroRPG soll ein modulares Rollenspiel mit Aufgaben, Verliesen, Monstern, Herstellung, Ausrüstung, Laden, Ereignissen und einem eigenen rundenbasierten Kampfsystem werden. Mehrere Personen sollen gleichzeitig spielen können.

## Technische Grundlage

- Skriptsprache: mIRC Scripting Language (MSL/MRC)
- IRC-Dienste: Anope und UnrealIRCd

## Entwicklungsgrundsätze

- Sämtliche Dokumentation und alle von uns verfassten Kommentare, Beschreibungen und Spielmeldungen sind auf Deutsch.
- Die Spielsysteme werden in getrennte, nachvollziehbare Module aufgeteilt.
- Die Entwicklung erfolgt schrittweise; Funktionen werden einzeln geprüft und getestet.
